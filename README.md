#  XML ⇄ JSON Converter (JavaFX)

##  Description du Projet
Application de bureau développée en **JavaFX** permettant la conversion bidirectionnelle entre **XML** et **JSON**.
Ce projet compare deux approches :
1. **Approche Manuelle :** Algorithme de parsing développé "from scratch" (sans librairie) pour comprendre la logique.
2. **Approche API :** Utilisation de la librairie standard `org.json` pour une conversion robuste.
